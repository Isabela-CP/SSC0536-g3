## 🏗️ Arquitetura e Componentes
✅ **Decisões acertadas:**
- **Fonte única da verdade:** A criação de `REVIEW_GUIDE.md` como diretriz centralizada para a IA e para os desenvolvedores é uma excelente prática de governança.
- **Resiliência:** A implementação de *fallback* entre diferentes modelos de LLM (`gemini`, `openai`, `anthropic`) no script Python (`review_pr.py`) garante que a pipeline de CI não seja um ponto único de falha.
- **Integração CI:** O uso do GitHub CLI (`gh`) dentro do workflow permite uma comunicação fluida e nativa com o ecossistema do repositório.

## 🟡 Não bloqueia
