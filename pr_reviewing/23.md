# PR #23 — feat(qa): implementa agente de IA para code review contínuo (SCRUM-86)

## O que o PR faz (`22-qa-scrum-86-implementar-agente-de-ia-para-code-review-contínuo` → `Develop`)
O PR implementa um sistema de automação para revisão de código via IA, integrando o GitHub Actions (workflow `pr-review.yml`) com um script Python (`review_pr.py`) que consome a API de modelos de linguagem (Gemini/OpenAI/Anthropic).

## 🏗️ Arquitetura e Componentes
✅ **Decisões acertadas:**
- **Fonte única da verdade:** Centralizar os critérios em `.github/review/REVIEW_GUIDE.md` é uma excelente prática, facilitando a manutenção e garantindo consistência entre o workflow e a skill local.
- **Flexibilidade:** A inclusão de suporte a múltiplos provedores de LLM (`anthropic`, `openai`, `gemini`) no script Python torna a ferramenta resiliente a indisponibilidades ou limites de cota.
- **Workflow robusto:** O pipeline de CI (checkout, build, script, postagem de comentário) está bem estruturado e focado na qualidade do código.

## 🟡 Não bloqueia
- **Robustez do script:** O script Python faz o parse do diff. Caso o diff seja muito grande ou mal formatado em casos extremos, o prompt pode ser truncado. A estratégia de truncamento atual (30k caracteres) é prudente, mas monitorar se ela impacta a qualidade da análise em PRs gigantes é recomendado no futuro.
- **Segurança:** O script utiliza `shell=False` (implícito via `subprocess` não utilizado diretamente, mas com `urllib`), o que é bom. Certifique-se de que os segredos da API não sejam logados caso ocorra um erro na execução do script.

## ℹ️ Para registro
