# PR Reviews — SSC0536-g3 (OTO Hospedagem)

Histórico de revisões de Pull Requests feitas pela IA (workflow `AI PR Review`) e pela equipe.

- Cada revisão é salva como `<numero-do-pr>.md` (ex: `12.md`).
- O workflow salva o arquivo automaticamente na branch do PR após cada review.
- Formato e critérios de veredito: veja [`.github/review/REVIEW_GUIDE.md`](../.github/review/REVIEW_GUIDE.md).
