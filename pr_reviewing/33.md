## 🏗️ Arquitetura e Componentes
✅ **Decisões acertadas:**
- **Separação de responsabilidades:** A criação de `InventoryRepository` (protocolo) e `JsonInventoryRepository` facilita muito a migração futura para um banco SQL sem alterar as rotas HTTP.
- **`InventoryRoute` Customizada:** Centralizar a tradução de exceções (`RequestValidationError`, `HTTPException`) para o padrão `ErrorResponse` do contrato é uma excelente prática para manter a API limpa e consistente.
- **Validação de Contrato:** O uso de `jsonschema` nos testes garante que a implementação nunca divirja do `openapi.json`.
- **Isolamento de HOTEL:** A implementação do filtro de escopo no servidor protege corretamente os dados dos estabelecimentos.
